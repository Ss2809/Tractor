## ✨ Features

- 🎵 YouTube playlist integration
- ▶️ Play / Pause music
- ⏭️ Next / Previous song
- 📋 Playlist support
- 📊 Live song progress
- 🕐 Live clock
- 🔊 Horn button
- 🚚 Dynamic background images
- 🎨 Glassmorphism UI
- 📱 Mobile responsive design
- 💾 Remembers the last played song
- 📱 Android app support with Capacitor

---

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| React.js | Frontend |
| Vite | Build Tool |
| Tailwind CSS | UI Design |
| JavaScript | Logic |
| Lucide React | Icons |
| YouTube Data API | Playlist |
| Capacitor | Android App |
